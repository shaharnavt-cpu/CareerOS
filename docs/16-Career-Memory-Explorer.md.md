# 17. Career Memory Visualization

*"People do not remember their lives as spreadsheets. They remember
journeys, places, relationships, and stories."*

## Purpose

CareerOS is designed to help people explore, understand, and remember
the story of their professional lives through a living world rather than
traditional dashboards.

## Core Philosophy

-   CareerOS visualizes meaning, not data.
-   Every user's world is unique.
-   The world grows because the user's career grows.
-   Growth reflects reality rather than artificial gamification.

## Architecture

Career Memory

↓

Semantic Graph

↓

Relationship Engine

↓

Semantic Physics Engine

↓

AI World Designer

↓

Renderer

↓

Theme

Each layer has a single responsibility.

## Semantic Graph

Stores deterministic relationships including:

-   belongs to
-   created
-   depends on
-   collaborated with
-   influenced
-   shares experience with
-   supports
-   precedes
-   follows

## Relationship Types

### Hierarchy

Hierarchy is itself a relationship.

Example:

UT Austin → GEVIP → Capstone → AAS Poster

Hierarchy determines containment and should have a unique visual
behavior.

### Influence

Determines gravity, mass, and long-term importance.

### Dependency

Represents 'could not exist without.'

### Collaboration

Represents people building something together.

### Shared Experience

Career memories never merge.

Shared experiences create shared gravitational influence between
independent Career Worlds.

### Temporal

Represents before, after, and concurrent relationships.

## Semantic Physics Engine

-   Distance → semantic closeness
-   Orbit → hierarchy and dependency
-   Mass → influence
-   Brightness → confidence
-   Motion → recent activity
-   Resonance → shared experiences
-   Constellations → emergent groups
-   Growth → accumulated evidence

## AI World Designer

AI artistically interprets Career Memory while deterministic systems
preserve semantic truth.

Example:

UT Austin → Star

GEVIP → Planet

Capstone → Moon

Poster → Satellite

The visualization is procedurally interpreted rather than procedurally
generated.

## Renderers

-   Galaxy
-   City
-   Tree
-   Timeline
-   Dashboard

All renderers visualize the same underlying Career Memory.

## Personalization

Themes change aesthetics.

Renderers change metaphors.

Neither changes meaning.

## Goals

Goals appear as future destinations that become clearer as progress is
made.

## Version History

Every approved Career Memory update creates a new version of the world.

Users can revisit previous worlds and trace changes back to evidence.

## Design Principles

1.  Meaning over decoration.
2.  Every visual behavior has semantic meaning.
3.  Career Memory is never altered by the renderer.
4.  AI interprets; deterministic systems preserve truth.
5.  Growth reflects reality.
6.  Shared experiences connect worlds without merging them.
7.  Users remain in control.
8.  Inspire curiosity.
9.  Encourage reflection.
10. Make users proud of how far they have come.
