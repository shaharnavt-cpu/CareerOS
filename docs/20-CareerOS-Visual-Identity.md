# CareerOS Visual Identity

CareerOS is a professional memory studio: a calm workspace where a person
shapes evidence into career memory, stories, and application answers.

## Product metaphor

CareerOS is not a chatbot. It is a living professional map.

- Evidence points are the trail.
- Approved memories are durable landmarks.
- Stories are routes through related landmarks.
- Applications are fit maps between an opportunity and approved memory.

## Design principles

- High trust: evidence, approval status, and source counts should be visible.
- Calm focus: use warm neutrals, deep green, soft borders, and clear hierarchy.
- Structured creativity: make the user feel like they are arranging a meaningful
  professional map, not chatting with a generic assistant.
- No mystery meat: every AI proposal should expose why it exists and what memory
  it uses.
- Demo resilience: empty/error states should always suggest the next safe step.

## Key surfaces

- Dashboard: command center and MVP flow progress.
- Review: memory workbench with editable, evidence-backed cards.
- Stories: story ingredients and proposed narrative maps.
- Applications: application fit map, approved-memory matches, and draft studio.

## Language guidelines

Prefer:

- "approved memory"
- "evidence trail"
- "story ingredients"
- "application fit map"
- "draft from approved memory"
- "supporting evidence saved"

Avoid:

- generic "AI chat" language;
- unsupported claims;
- cute/game-like wording;
- fear-heavy gap language;
- low-context labels like "item" when "memory", "evidence", or "draft" is more
  precise.

## What to avoid

- Random gradients or heavy animation.
- Low-contrast pale text.
- Chat bubbles as the dominant interface.
- Hiding evidence behind polished prose.
- Making the app feel like a game instead of a serious career tool.
